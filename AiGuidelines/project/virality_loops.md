# Porta — Virality and Re-engagement

> The starter kit's growth template assumes a paywall, credits and push notifications. Porta's contest build has none
> of these, so this file records Porta's deliberate position instead of filling in that template.

## Multi-surface monetization

None. Porta is completely free during the contest (see `paywall.md`). No conversion prompt, usage limit, streak
reward or win-back offer exists.

## Share / referral loop

No referral incentive. The honest shareable artefacts already exist and stay user-initiated:

- **Profile export** — versioned JSON for moving a profile between the user's own Android and Desktop installs. It
  warns about the sensitive categories it contains and never includes evidence binaries.
- **Opportunity pack export** — a curator can share a validated pack. The receiver sees an approval diff before
  activation.

Any future sharing must keep those boundaries: no automatic upload, no contact scraping, and no shared artefact that
implies admission, funding or selection.

## Re-engagement

None in the contest build: there are no notifications or reminders. Deadline reminders are a P1 idea in
`MobileApp/PORTA_PRD.md`. If they are added, they must:

- be opt-in and tied to a deadline or plan step the user saved;
- never invent a date for a TBA or rolling deadline;
- never use urgency copy that implies a chance of selection.

## Ethics

Honest means only. No fake scarcity, guilt, dark patterns, or claims that a step guarantees an outcome.
