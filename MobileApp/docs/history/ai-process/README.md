# Porta AI-assisted development archive

This directory preserves one-off prompts, audits, implementation plans, verification snapshots, and visual-design
notes produced during Porta's contest-period development. They remain public for process transparency and Git
provenance, but they are **historical artifacts**, not the current product or submission status.

Use the following documents as the current sources of truth:

- [`../../../README.md`](../../../README.md) — product overview, declared targets, and launch instructions.
- [`../../../PORTA_PRD.md`](../../../PORTA_PRD.md) — current product scope and acceptance criteria.
- [`../../../CONTEST_SCORECARD.md`](../../../CONTEST_SCORECARD.md) — contest readiness and unresolved gates.
- [`../../../KMP_EVIDENCE.md`](../../../KMP_EVIDENCE.md) — shared-Kotlin measurement and exclusions.
- [`../../../OPPORTUNITY_PACK_SOURCES.md`](../../../OPPORTUNITY_PACK_SOURCES.md) — opportunity-source register.
- [`../../../SUBMISSION/`](../../../SUBMISSION/) — essay, demo, media, and fresh-setup materials.

The repository's reusable agent instructions and skills remain in their original locations. Moving these one-off
documents here changes no source code, Gradle paths, runtime behavior, or Git history.
